# S04-B3 - Recorrer registros con `for`

## Objetivo

Recorrer todos los registros de producción y mostrar datos de cada uno.

## Conocimiento esencial

- `for registro in registros` visita cada diccionario de la lista, uno por uno.
- `in` indica que se recorren los elementos contenidos en `registros`.
- La variable `registro` representa un diccionario diferente en cada vuelta.
- Las claves `producto` y `unidades_producidas` permiten mostrar datos concretos de cada registro.

## Lo que construyó el estudiante

Usó un solo ciclo `for` para mostrar el producto y las unidades producidas de los dos registros.

## Evidencia

- Archivo: `practica_s04.py`
- Revisión: se trabajó con la lista de diccionarios de producción.
- Ejecución: observada; se obtuvo Producto A (850) y Producto B (800).
- Explicación: comprendió que la variable cambia de registro en cada vuelta.
- Método de validación: salida de consola y explicación propia.
