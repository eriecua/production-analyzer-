# S07-B1 - Separar responsabilidades

## Objetivo

Distinguir lectura, validación, cálculo y presentación antes de reorganizar el código.

## Conocimiento esencial

- Recibir significa obtener los datos desde el CSV.
- Validar significa comprobar reglas, como que los defectos no superen la producción.
- Calcular significa producir un indicador, como unidades buenas.
- Presentar significa mostrar el resultado con `print()`.
- `for` recorre datos ya cargados; no necesariamente lee el archivo.
- `int()` prepara un texto numérico para poder operar con él.

## Lo que construyó el estudiante

Clasificó las piezas existentes del analizador por responsabilidad y describió el flujo de una fila de producción sin escribir código nuevo.

## Evidencia

- Archivo de referencia: `practica_s06.py`
- Revisión: se inspeccionaron las funciones, condiciones, conversiones, recorrido y salidas existentes.
- Ejecución: no se añadió código en este bloque; las piezas de referencia ya tenían ejecuciones observadas.
- Explicación: demostrada; identificó validación, cálculo y presentación con ejemplos del proyecto.
- Método de validación: explicación guiada y clasificación conceptual de piezas reales.
