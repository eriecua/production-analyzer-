# S05-B2 - Crear el CSV de ejemplo

## Objetivo

Crear un archivo CSV válido con la estructura de datos del analizador de producción.

## Conocimiento esencial

- La primera fila contiene ocho encabezados o columnas.
- Cada fila posterior representa un registro de producción.
- Los valores están separados por comas y conservan el mismo orden que los encabezados.
- El archivo `.csv` es texto estructurado, no código Python.

## Lo que construyó el estudiante

Creó `produccion_ejemplo.csv` con dos registros completos: Producto A y Producto B.

## Evidencia

- Archivo: `produccion_ejemplo.csv`
- Revisión: ocho encabezados y dos filas completas verificadas.
- Ejecución: el archivo fue leído posteriormente por Python.
- Explicación: distinguió columnas de registros y ubicó valores concretos.
- Método de validación: lectura directa del archivo y uso desde el script.
